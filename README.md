# 🌾 मोती नगर डिजिटल ग्राम एवं पंचायत कनेक्ट (Moti Nagar & Gudha Gram Connect)

एक अत्याधुनिक, आधुनिक और नागरिक-हितैषी डिजिटल पंचायत पोर्टल। यह पोर्टल ग्राम पंचायत गुढ़ा एवं राजस्व ग्राम मोती नगर (तहसील इन्द्रगढ़, जिला बूंदी, राजस्थान) के नागरिकों को ई-सेवाएं, सरकारी योजनाएं, चुनावी डेटा, लाइव मंडी भाव, मौसम और आपातकालीन सहायता प्रदान करता है।

---

## 🌟 प्रमुख विशेषताएं (Key Features)

1. **🌾 लाइव कोटा मंडी भाव (Live Mandi Bhav)**
   - कोटा भामाशाह मंडी, लाखेरी उप-मंडी और बूंदी मंडी के 12+ प्रमुख जिंसों (सोयाबीन, सरसों/रायड़ा, देशी लहसुन, चना, गेहूँ, धान, उड़द, आदि) के न्यूनतम, अधिकतम और मॉडल भाव।
   - स्रोत: [khetiwadi.com](https://khetiwadi.com/mandi/kota-mandi-bhav).

2. **☀️ लाइव मौसम एवं कृषि सलाह (Real-time Weather & Advisory)**
   - मोती नगर के सटीक अक्षांश-देशांतर (`25.7985° N, 76.2161° E`) के आधार पर लाइव तापमान, आर्द्रता, वर्षा संभावना एवं मौसमी रबी/खरीफ कृषि परामर्श (Open-Meteo & IMD डेटा)।

3. **🗳️ 2026 मतदाता सूची खोज व डिजिटल पर्ची (Voter Search & Slip Generator)**
   - ग्राम पंचायत गुढ़ा के सभी **वार्ड 1 से 7** (बूथ 6, 7, 8, 9 - कमरा नं. 8, 9, 10, 11) के मतदाताओं का नाम/वार्ड से त्वरित सर्च।
   - बूथ, रूम नंबर व बीएलओ विवरण के साथ डिजिटल मतदाता पर्ची डाउनलोड/प्रिंट करने की सुविधा।

4. **🚨 24x7 आपातकालीन SOS स्पीड डायल (Emergency SOS Panel)**
   - एम्बुलेंस (108), पुलिस (112), महिला हेल्पलाइन (181), विद्युत फॉल्ट (1912), ग्राम विकास अधिकारी (VDO) व सीएचसी डॉक्टर डायरेक्ट कॉलिंग।

5. **📢 डिजिटल मुनादी (Digital Voice Munadi Player)**
   - Web Speech Synthesis इंजन द्वारा गाँव की महत्वपूर्ण सरकारी घोषणाओं का ऑडियो लाउडस्पीकर प्रसारण।

6. **💬 वॉट्सऐप ग्राम नागरिक सहायता डेस्क (WhatsApp Helpdesk)**
   - राशन कार्ड, पेयजल, बिजली शिकायत व प्रमाण पत्र जानकारी हेतु डायरेक्ट वॉट्सऐप इंटिग्रेशन।

7. **📋 ई-मित्र आवेदन स्टेटस ट्रैकर (E-Service Token Tracker)**
   - टोकन नंबर द्वारा 4-चरणों वाला लाइव एप्लिकेशन स्टेटस ट्रैकर (आवेदन ➔ पटवारी जांच ➔ अनुमोदन ➔ प्रमाण पत्र जारी)।

8. **🏠 समृद्ध ग्राम प्रोफाइल व संवादात्मक मानचित्र (Interactive Village Map)**
   - ग्राम परिचय, इतिहास, जनसंख्या व जनसांख्यिकी (लिंगानुपात, साक्षरता), प्रमुख स्थल (महा शॉप, माताजी मंदिर, राजकीय विद्यालय) एवं गूगल मैप्स लिंक।
   - सटीक स्थान: `25.7985349, 76.2160933` | [Google Maps](https://maps.app.goo.gl/GM47mAhRpmHp5qYw6)

9. **🌾 समर्पित किसान कल्याण हब (Dedicated Farmer Hub — `/farmer-hub`)**
   - **लाइव मौसम व 5-दिवसीय कृषि पूर्वानुमान**: सटीक सैटेलाइट व IMD डेटा।
   - **मंडी भाव (Mandi Prices)**: कोटा भामाशाह, लाखेरी व बूंदी मंडी भाव खोज व तुलना।
   - **फसल ज्ञानकोश (Crop Database)**: सोयाबीन, सरसों, गेहूं, धान, देशी लहसुन व चना की बुवाई, बीज दर, रोग रोकथाम व उपज गाइड।
   - **किसान सब्सिडी योजनाएं**: खेत तारबंदी (₹48,000 अनुदान), पीएम कुसुम सोलर पंप (60%), ड्रिप/स्प्रिंकलर (70%), कृषि यंत्र सब्सिडी।
   - **KVK साप्ताहिक परामर्श**: कृषि विज्ञान केंद्र बूंदी व कोटा विश्वविद्यालय की समसामयिक एडवाइजरी।
   - **चंबल नहर सिंचाई रोस्टर**: दांयी मुख्य नहर (RMC) लाखेरी वितरिका जल बारी एवं फार्म पॉन्ड योजना।
   - **पशुपालन व डेयरी हब**: मुख्यमंत्री कामधेनु पशु बीमा (₹40,000), निःशुल्क दवा, सरस डेयरी FAT/SNF भाव व पशु एम्बुलेंस (1962)।
   - **खाद-बीज कैलकुलेटर**: बीघा अनुसार यूरिया, डीएपी, पोटाश व जिंक की सटीक बोरी गणना।
   - **किसान हेल्पलाइन**: 1800-180-1551 (Kisan Call Center), 1912 (विद्युत), 14447 (फसल बीमा)।

## 🛠️ तकनीकी स्टैक (Tech Stack)

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Icons**: Lucide React
- **Weather API**: Open-Meteo REST API
- **TTS Engine**: Web Speech API

## 🚀 स्थानीय स्तर पर चलाएं (Run Locally)

```bash
# 1. रिपॉजिटरी क्लोन करें
git clone https://github.com/Pravinkumar0908/motinagar.git

# 2. प्रोजेक्ट फोल्डर में जाएं
cd motinagar

# 3. निर्भरताएं (dependencies) इंस्टॉल करें
npm install

# 4. डेवलपमेंट सर्वर शुरू करें
npm run dev
```

ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलें।
